直列 RLC インピーダンス計算機

理想的な直列 RLC 回路の正弦波定常状態におけるインピーダンスの大きさを計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

0 以上

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

インピーダンスの大きさ |Z|

—

値を入力し「計算する」を押してください。

公式

|Z| = √(R²+(2πfL−1/(2πfC))²)

適用条件

R≥0、L,C,f>0。理想素子を直列接続した正弦波定常状態を仮定します。インピーダンスの大きさだけを返します。寄生成分、飽和、非線形性は考慮しません。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
